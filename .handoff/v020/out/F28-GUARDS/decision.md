| D370 | Managed trust anchors: SQLite-only scope, image-less refusal and the mixed-version position | (1) Config validation refuses `upstreams.recursion.anchorMode: managed` unless `store.driver` is `sqlite`. On the Kubernetes driver this covers startup, settings reloads through the settings manager (the shared settings ConfigMap; a refused reload keeps the last good configuration) and settings PATCH validation, which refuses before anything is stored. (2) A node without an installed cluster image never enters a managed topology lane. An unenrolled receiver (a join that never installed its first image, D356), started with `direct` or `edges`, and any image-less node started with `edges` both get one specific startup refusal that names `cluster join --offline` and `cluster join-reconcile --offline`. The refusal comes before any edge observation or root fetch and writes nothing. The offline join (D355/D356) is the only first-image lane, so there is no waiting lane for edges. A direct follower enrolled without an image, which no production path creates, keeps its existing wait. (3) Members exchange anchor history only inside complete images gated by the exact store schema (9) and required-feature list. The inner formats are not negotiated separately: pure 1, recovery 2, owner envelope 1 and local carrier 1. Recovery format 2 was added at schema 8, before schema 9. The only earlier release, v0.1.0 (schema 1), has no managed anchors, so no format-1-only binary was released and none can exchange a v0.2.0 image. Unknown inner formats are refused, and the receiver's image, authority and carrier stay unchanged. Committed golden documents pin each format's bytes and version digests, and a tripwire test pins the whole tuple. Any later pure, recovery, envelope or local carrier format change must come with a schema or RequiredFeatures bump. Operators check only that every member runs v0.2.0 or later (F28-MV-1 evidence; released-binary process acceptance is F28-MV-2). | On Kubernetes the managed setting silently built the resolver from the seeds as static anchors, which promised RFC 5011 and did nothing (G21). A generic "policy unavailable" error at startup gave an operator with an incomplete join no remedy, and D319 forbids waiting for or recapturing an image after a remote observation. The only compatibility proof of the inner formats lived outside the tree.
