# web

The kudurru dashboard (dev-docs/design-record.md §10, decision D69): a single-page
app embedded into the binary with `go:embed` and served by `web.Handler`.

- **Toolchain:** Bun (package manager, script runner) with Vite 8 (rolldown)
  for the dev server and production build, Vitest + Testing Library for tests.
- **UI:** React 19 + TypeScript (strict) with [Astryx](https://github.com/facebook/astryx)
  (`@astryxdesign/core` and the neutral/stone/y2k themes, MIT, consumed as
  prebuilt CSS and JS, pinned exactly while Astryx is in Beta).
- **Themes:** `src/themes` holds the Kudurru theme (`defineTheme` over
  Neutral with the palette generated from branding,
  `astryx theme palette generate`) and Neutral, Stone and Y2K extended with
  the query status colours. `bun run themes:build` rebuilds their committed
  `.js`/`.css` after a source change (`bun run lint` checks they are
  current); `src/astryx-themes.ts` is generated by
  `bun run astryx -- theme add <slug> --import` and not edited by hand.
- **Data:** TanStack Query; TanStack Table + Virtual for the query log;
  `EventSource` for the live tail.
- **Charts:** uPlot for the time series, ECharts (tree-shaken, loaded on
  demand) for the donuts, until `@astryxdesign/charts` is stable.
- **Delivery:** no CDN, no inline scripts (strict CSP from `web.DefaultCSP`),
  relative asset URLs and a `<base href>` rewritten by the Go handler, so one
  bundle serves under any path prefix.

## Commands

```sh
make dashboard-install   # bun install --frozen-lockfile
make dashboard-dev       # Vite dev server with the MSW mock API (no kudurru needed)
make dashboard-test      # vitest run
make dashboard-lint      # eslint (zero warnings) + built themes current + tsc --noEmit
make dashboard-build     # production bundle into dashboard/dist + license file + size budget + precompression
```

Inside `dashboard/`: `bun run dev` proxies `/api` to `KUDURRU_API`
(default `http://127.0.0.1:8080`) for work against a real server;
`bun run dev:mock` answers `/api/v1` in the browser from `src/mocks`.
Open `http://localhost:5173/?mockUser=admin` to skip the login form in
mock mode (users `admin`/`admin` and `viewer`/`viewer`).

`make build` never needs Bun. A placeholder `dashboard/dist/index.html` is
committed so `go build ./...` works on a plain checkout; `make dashboard-build`
overwrites it and writes the hashed bundle into `dashboard/dist/assets/` (ignored
by git). Do not commit the built `index.html`: `TestIndexAssetsPresent` in
this package fails when index.html references assets that are not embedded.

The last build step, `scripts/compress.ts`, replaces every compressible file
of at least 1 KiB except `index.html` with `<name>.gz` (gzip -9), so the
binary embeds about 0.8 MiB instead of 2.6 MiB. `web.Handler` sends the
stored gzip bytes with `Content-Encoding: gzip` (`Vary: Accept-Encoding`, an
ETag per representation) and inflates a file once for a client without
gzip. `KUDURRU_WEB_BROTLI=1 bun run build` also writes `<name>.br`, which
the handler prefers for clients that accept `br`, at the price of embedding
both. `dashboard/dist` therefore holds no plain `.js`/`.css` after a build; serve
it through the binary, not a static file server.

## Layout

| Path | What |
|---|---|
| `embed.go`, `handler.go` | `web.FS` (the bundle) and `web.Handler` (SPA fallback, caching, precompressed gzip/brotli, CSP, `<base href>` rewrite) |
| `src/api/` | the typed client: `types.ts` (wire types), `client.ts` (fetch, errors, CSRF), `endpoints.ts` (one function per route), `context.tsx` (session, permissions, node scope), `hooks.ts` |
| `src/pages/` | one lazily loaded module per route (`src/routes.tsx` is the table) |
| `src/components/` | shell, stat tiles, query-log table, record editor, generated object forms, settings rows, blocking control |
| `src/charts/` | uPlot stacked bars and the ECharts donut, both reading colours from CSS |
| `src/lib/` | router, base path, RR field model, settings metadata, formatting, ownership |
| `src/mocks/` | MSW handlers and deterministic fixtures (3 zones, 50 records, 6 lists, 4 groups, 3 policies, 24 h of series, 500 query rows, 2 nodes) |
| `scripts/` | `budget.ts` (initial-load gzip budget, default 600 KiB), `licenses.ts` (dist/third-party-licenses.txt) and `compress.ts` (stores the bundle as .gz for the binary) |

## Generated API types

v0.1.0 uses wire types generated from `api/openapi.json`.
`bun run gen:api` writes `src/api/generated.ts`; `src/api/types.ts` exposes
aliases such as `export type DNSZone = components['schemas']['DNSZone']`
and the dashboard's helper types. Regenerate the types when the API
contract changes; schema names are imported through `types.ts`.
