# Filtering

Use these tasks to change which names kudurru allows or blocks.

| Task | Guide |
|---|---|
| Add protection to the default policy | [Add a block list](add-list.md) |
| Restore a site that a list blocks | [Allow a blocked site](allow-site.md) |
| Apply different rules to devices | [Groups, clients and policies](../admin/05-groups-clients-policies.md) |
| Answer a user's access request | [Access requests](../admin/06-access-requests.md) |

Start with the [query log](../first-steps/queries.md) if you do not know
which name or rule causes a problem.
