# Use each dashboard page

**Before you start**

- Sign in to the dashboard.
- Use the role listed in each task. Unavailable actions need the named permission or a license key.

Choose the page you see in the app. Each guide gives actions and a result
to check. Screenshots show demo data.

| Dashboard page | How to use it |

| **Dashboard** | [Read activity and investigate a change](activity.md) |
| **Query log** | [Filter queries and explain an answer](query-log.md) |
