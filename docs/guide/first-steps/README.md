# First steps

Go from a new node to a client with working DNS. Follow these pages in order.
Each page ends with a check before you continue.

| Step | What you do |
|---|---|
| [1. Start a node](install.md) | Run kudurru with persistent storage |
| [2. Sign in](sign-in.md) | Open the dashboard and change the first password |
| [3. Connect a client](connect.md) | Test DNS, then change the network settings |
| [4. Read your first queries](queries.md) | See which names the client asks for and why kudurru answers |

**Before you start**

- You need a Linux host with a fixed address and Docker.
- You need access to the host and the network settings of a test client.
- You need the `admin` account after the first start.

For a cluster, start with the [Helm guide](../../deploy/helm.md), then continue
with [Sign in](sign-in.md).
