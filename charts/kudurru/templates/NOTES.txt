{{- $ns := .Release.Namespace -}}
{{- $edgeMode := include "kudurru.edge.mode" . -}}
kudurru {{ .Chart.AppVersion }} is installed in namespace {{ $ns }}
(mode={{ .Values.mode }}, {{ include "kudurru.workloadKind" . }}{{ if $edgeMode }}, edge={{ $edgeMode }}{{ end }}{{ if ne .Values.vip.provider "none" }}, vip={{ .Values.vip.provider }}{{ end }}).
{{- if eq .Values.mode "kubernetes" }}

The CRDs come from the kudurru-crds chart; install it first if you have not:
  helm install kudurru-crds oci://ghcr.io/robertherbaugh/charts/kudurru-crds
{{- end }}

1. Wait for the pods:
  kubectl -n {{ $ns }} rollout status {{ include "kudurru.workloadKind" . | lower }}/{{ $fullname }}

2. DNS address:
  kubectl -n {{ $ns }} get svc -l app.kubernetes.io/instance={{ .Release.Name }},kudurru.io/service{{ if .Values.service.dns.splitProtocols }} in (dns-udp,dns-tcp){{ else }}=dns{{ end }}
  dig @<EXTERNAL-IP> example.com

3. First login. The bootstrap admin is created at the first start from the
   Secret {{ include "kudurru.adminSecret" . }}{{ if not .Values.auth.bootstrapAdminSecret }} (generated by this chart and kept on uninstall){{ end }}:
  kubectl -n {{ $ns }} get secret {{ include "kudurru.adminSecret" . }} -o jsonpath='{.data.password}' | base64 -d; echo
{{- if .Values.ingress.enabled }}
  Open http{{ if .Values.ingress.tls }}s{{ end }}://{{ .Values.ingress.host }}/ and sign in as "admin".
{{- else }}
  kubectl -n {{ $ns }} port-forward svc/{{ $fullname }}-api {{ .Values.service.api.port }}:{{ .Values.service.api.port }}
  Open http://localhost:{{ .Values.service.api.port }}/ and sign in as "admin".
{{- end }}
   You are asked to choose a new password; the Secret is only read while no
   user exists, so rotating it later changes nothing.
{{- if .Values.auth.bootstrapToken.enabled }}
   Automation token (kdr_...):
  kubectl -n {{ $ns }} get secret {{ include "kudurru.bootstrapTokenSecret" . }} -o jsonpath='{.data.token}' | base64 -d; echo
{{- end }}

4. Health and metrics:
  kubectl -n {{ $ns }} port-forward svc/{{ $fullname }}-api 9153:9153
  curl -s localhost:9153/metrics | grep kudurru_build_info

{{- if and (not .Values.license.key) (not .Values.license.existingSecret) }}

5. License. No license key is configured, so kudurru runs with the free
   license: one node, one policy (the seeded default) and none of the
   licensed features (roles beyond the built-in administrator, OIDC, the
   audit trail, long-term statistics, unblock requests, the dnsdist and
   keepalived edge, integrations). DNS answering is not affected.
{{- if gt (int .Values.replicaCount) 1 }}
   replicaCount is {{ .Values.replicaCount }}, which is over the limit of one node:
   changes through the API and the dashboard answer 402 license_required until
   a key is in place. Changes with kubectl are not affected.
{{- end }}
   A free personal key covers up to 3 nodes for non-commercial use
   (https://kudurru.io/license). Put it in a Secret and set the value:
  kubectl -n {{ $ns }} create secret generic kudurru-license --from-file=license.key=./license.key
  helm upgrade {{ .Release.Name }} ... --set license.existingSecret=kudurru-license
{{- end }}

Keep the encryption key Secret {{ include "kudurru.encryptionKeySecret" . }}: it seals
sessions and stored secrets and derives the node-to-node credentials. Rotation
is described in docs/deploy/runbooks.md.
{{- if $edgeMode }}

Edge: the dnsdist supervisor image (kudurru edge run) is a milestone M4
deliverable. Until it is published the edge pods do not start; set
edge.enabled=false to serve DNS from the kudurru pods directly.
{{- end }}

namespace for the privileged Pod Security level and the VIP nodes with
{{ include "kudurru.labelSelector" .Values.vip.keepalived.nodeSelector }}.
{{- end }}
