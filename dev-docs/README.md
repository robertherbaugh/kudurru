# Developer documentation

Notes for people working on kudurru. None of this is published to
docs.kudurru.io; the user documentation is in [docs/](../docs/), and the
[architecture tour](../docs/architecture/README.md) explains how the code
works today.

| File | What it is |
|---|---|
| [design-record.md](design-record.md) | The design record: vision, design and the decision log (D1, D2, ...) that code comments cite as `§<section>` and `D<number>` |
| [milestones/](milestones/) | Reports from each milestone before v0.1.0: [M1](milestones/m1/README.md), [M2](milestones/m2/README.md), [M3/M4](milestones/m3/README.md), [M5](milestones/m5/README.md) |
| [spikes/](spikes/README.md) | Week-1 spike reports: what was built and measured before the design was fixed |
| [research/](research/README.md) | Point-in-time studies of the projects kudurru learns from |
| [followups.md](followups.md) | Known follow-up work |
| [open-questions.md](open-questions.md) | Questions left to the project owner and how they were answered |
| [release-checklist.md](release-checklist.md) | The release pipeline and the checks around each release |
