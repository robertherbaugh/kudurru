# kudurru: notes for AI coding agents

- Dashboard (`web/`): the React + Astryx SPA. Before changing it, read
  [web/AGENTS.md](web/AGENTS.md) (generated by `astryx init --features agents`;
  refresh it with `cd web && bun run astryx -- upgrade --from <old> --apply`
  after an Astryx bump) and look up every component with
  `cd web && bun run astryx -- component <Name> --dense` before using it.
  Docs: `bun run astryx -- docs <topic>`; search: `bun run astryx -- search "<query>"`.
- The UI rules in docs/m3/ui.md ("Pages, wizards and dialogs") apply on top.
- Everything else: docs/architecture.md, CONTRIBUTING.md, docs/followups.md.
