# kudurru: notes for AI coding agents

- Write American English, not British English, everywhere: code, comments,
  identifiers, docs, UI copy, commit messages and PR text. For example, use
  "color", "behavior", "initialize", "canceled", "license" (noun), "catalog",
  not "colour", "behaviour", "initialise", "cancelled", "licence", "catalogue".
  When you touch a line that has British spelling, fix it.
- Dashboard (`dashboard/`): the React + Astryx SPA. Before changing it, read
  [dashboard/AGENTS.md](dashboard/AGENTS.md) (generated by `astryx init --features agents`;
  refresh it with `cd dashboard && bun run astryx -- upgrade --from <old> --apply`
  after an Astryx bump) and look up every component with
  `cd dashboard && bun run astryx -- component <Name> --dense` before using it.
  Docs: `bun run astryx -- docs <topic>`; search: `bun run astryx -- search "<query>"`.
- The UI rules in dev-docs/milestones/m3/ui.md ("Pages, wizards and dialogs") apply on top.
- License portal (`license-server/`): read
  [license-server/AGENTS.md](license-server/AGENTS.md) first. Its UI uses the
  same Astryx rules (look components up with
  `cd license-server && bun run astryx -- component <Name> --dense`).
- How it works today, with diagrams: docs/architecture/ (keep its pages and
  diagrams in step with the code when you change a flow it shows).
- Everything else: dev-docs/design-record.md (design record and decision log),
  CONTRIBUTING.md, dev-docs/followups.md.
